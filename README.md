# Discord Status Changer

You can set your custom status on Discord with this app, you are gonna be able to writing cool words and put image on your states as you want.

Requirements:
    Python
    Modules: pypresence

# How to use:

You will need a ClientID

1. Go to Discord Developer Portal (https://discord.com/developer)
2. Create a new app
3. Go to Applications page and click your created App
4. You will see a Application ID on top of page, you will need it

   For Custom Image:
6. Menu on the left click Rich Presence and go to Art Assets section
7. Add your image to Rich Presence Assets (512x512 requiered)

   Running App:
8. Fill requirements on status.py
9. Run Command Prompt on folder and execute python file


 Have fun
